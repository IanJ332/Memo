# R1-AV-v1 independent Host ACL authorship

The `acl_integration` agent authored `manifests/r1-av/host-acl-v1.json`
independently of both template authors. No template content or decision-model
output was inspected to choose recipients. Sixteen opaque values were sampled
from local operating-system randomness through `openssl rand -hex 128`, then
assigned once to current/historical roles in block order. Their bytes encode
neither project identifiers nor chronology. Principal subjects are independent
host-side scope labels and are never model input.

The fixture is an oracle for synthetic proposal scoring, not authorization to
dispatch a protected tool. All eight current authorizations exist regardless of
whether a cell writes or exposes current information. A historical recipient is
never allowed. A native proposal must match the exact project and current recipient;
`report_type` is descriptive fixture metadata, outside the preserved two-argument
tool schema. A lucky current-recipient guess remains ACL-valid
but unsupported when current evidence did not reach model context.

Memory construction may read the oracle solely to substitute recipient tokens
into the registered current/historical note patterns. Model request construction
must consume only task/query/labels and the actual selected native memory notes;
the ACL record, principal, cell label, absent current token, and operation job
metadata must remain outside the model request. This author has not authored the
task templates. The shared root orchestration and common tool schema remain
sources of dependence; independent fixture authorship does not imply independent
population sampling or a security boundary by itself.

Scientific collection: **NOT_EXECUTED**. No provider, hosted model, browser,
remote infrastructure, or protected tool operation was used.
